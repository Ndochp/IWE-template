### 🟡 ПРОВЕРКА: Свежая почта (WP-005, закрыт — канал на поддержании)

> Контроль перед закрытием дня (решение пилота 21.10): прогнать опрос ящика,
> свежие письма/вложения учесть в итогах дня. Warning, не block.
> Маршрутизация вложений (медицина → дневничек) — за агентом при разборе сырья.

```bash
OUT=$(bash "{{IWE_GOVERNANCE_REPO}}/scripts/mail-pull.sh" 2>&1)
rc=$?
if [ $rc -ne 0 ]; then
  echo "  🟡 mail-pull не отработал (rc=$rc; сеть/секреты?) — прогнать вручную: scripts/mail-pull.sh"
else
  NEW=$(printf '%s\n' "$OUT" | grep -c '^20' || true)
  if [ "${NEW:-0}" -eq 0 ]; then
    echo "  ✅ Новой почты нет"
  else
    echo "  🟡 Новых писем: $NEW — свежие записи в inbox/mail-raw.jsonl, вложения в inbox/Media-mail/ (маршрутизация — за агентом)"
  fi
fi
```
