# Day Open — Тайминг дня (правило пилота, 2026-09-21)

> **Когда:** шаг после формирования dashboard (hook: after).
> **Что проверять:** есть ли отчёт по таймингу за вчера (данные трекинга времени за предыдущий день — где и как их ведёт пилот, уточнять отдельно).
> **Действие:** если отчёта за вчера нет — задать отдельный вопрос «есть отчёт по таймингу за вчера?» (отдельно от общего ответа Day Open).
> **Правило:** спрашивать каждый день при Day Open, пока отчёт за вчера не появится. Отчёт запрашивается отдельно, не сливается с другими вопросами.
> **Исполнение (чинка 16.10):** бегунок графа расширений (`day-open-hooks-runner.sh`)
> механически eval'ит bash-блоки и считает файл без блоков провалом — из-за этого
> шага без блока конвейер открытия дня абортится на шаге 4.8. Ниже — блок,
> задающий отдельный вопрос в Telegram каждый день. Расположение отчёта по таймингу
> не определено («уточнять отдельно»), поэтому проверка наличия отчёта не делается:
> вопрос идёт ежедневно, пока пилот не ответит «есть» и не укажет путь для проверки.

```bash
if [ -f "/tmp/iwe-dry-run.flag" ]; then
    echo "[extension day-open.after.timing] dry-run active, skipping"
    exit 0
fi
HOOK_IWE="${IWE_ROOT:-${IWE:-$HOME/IWE}}"
HOOK_DS="$HOOK_IWE/${IWE_GOVERNANCE_REPO:-DS-strategy}"
HOOK_YDAY=$(date -d "yesterday" +%F 2>/dev/null || date -v-1d +%F 2>/dev/null || echo "?")
HOOK_TG_LIB="$HOOK_DS/scripts/lib/telegram.sh"
if [ -f "$HOOK_TG_LIB" ]; then
    # shellcheck disable=SC1090
    . "$HOOK_TG_LIB" 2>/dev/null || true
    telegram_load_creds 2>/dev/null \
        && telegram_send "⏱ Есть отчёт по таймингу за $HOOK_YDAY? (отдельный вопрос правила 21.09 — спрашиваю каждый день, пока отчёт не появится)" 2>/dev/null \
        || echo "[timing] вопрос в Telegram не отправлен (нет кредов/сети)"
fi
exit 0
```
