# day-open.before.reflection-dogon — догон вечерней рефлексии на открытии дня (WP-007 Ф1)

> **Hook:** `day-open` / `before` (перед шагом 1 «Вчера»).
> **Правило (сессия W46, этап 3):** день без вечерней рефлексии открывается догоном вчерашней.
> Догон — штатный исход, в «Требует внимания» не пишется.
> **Граница (правило пилота, 11.11):** 2–3 минуты; рефлексия не конкурирует с утренним выходом на работу.
> **Политика отказов:** bash-блок не блокирует открытие (exit 0).

```bash
if [ -f "/tmp/iwe-dry-run.flag" ]; then
    echo "[reflection-dogon] dry-run active, skipping"
    exit 0
fi
GOV="${IWE_GOVERNANCE_REPO:-DS-strategy}"
WS="${IWE_ROOT:-${IWE:-$HOME/IWE}}"
YDAY=$(date -d "yesterday" +%F 2>/dev/null || date -v-1d +%F 2>/dev/null)
[ -z "$YDAY" ] && { echo "[reflection-dogon] дата «вчера» не вычислена — пропуск"; exit 0; }
PLAN="$WS/$GOV/archive/day-plans/DayPlan $YDAY.md"
[ -f "$PLAN" ] || PLAN="$WS/$GOV/current/DayPlan $YDAY.md"
if [ ! -f "$PLAN" ]; then
    echo "[reflection-dogon] DayPlan за $YDAY не найден — проверка неприменима"
    exit 0
fi
if grep -qE "Рефлексия вечера|Рефлексия \(догон|Рефлексия \(вечер|Рефлексия \(первый вечер" "$PLAN"; then
    echo "[reflection-dogon] 🟢 рефлексия за $YDAY зафиксирована"
else
    echo "[reflection-dogon] 🟡 рефлексия за $YDAY отсутствует — догон: три вопроса («сработало / не сработало / главное на завтра»), ответы — в DayPlan сегодня, секция «Итоги вчера», блок «Рефлексия (догон $YDAY)»; строкой ниже, без «Требует внимания»"
fi
exit 0
```

Порядок для агента: при жёлтом статусе — в начале Day Open (сразу после чтения «Вчера») задать пилоту три вопроса одной строкой, ответы вписать в секцию «Итоги вчера» сегодняшнего DayPlan блоком `**Рефлексия (догон DD.MM):** 1. Сработало: … 2. Не сработало: … 3. Главное на завтра: …`. Пилот отказался (утром некогда) — записать «догон не состоялся (утро без слота)» и не напоминать в тот же день.
