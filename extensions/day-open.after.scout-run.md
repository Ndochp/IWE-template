# day-open.after.scout-run — скаут в Opening дня однопотоком (решение пилота 18.11)

> **Решение пилота 18.11:** скаут вынут из ночного цикла и запускается как часть Day Open, в том же потоке, без субагентов. Правило однопоточности от 16.10 сохраняется: один прогон, без очереди.
> **Цикл:** на этой машине планировщик не развёрнут — вынимать из расписания нечего. На машинах с ночным launchd-скаутом задача `com.iwe.scout` выгружается отдельно (команда пилоту, не агенту).

## Для агента

После шага 6b2 (разметка ТВС), до шага 7a (запись DayPlan):

1. Прогнать разведку по алгоритму скилла `/scout` (окно 24 ч; выходные — 48 ч): коммиты репо, issues (FMT/FPF), новости из `day-rhythm-config.yaml → news.topics`, новые заметки ящика.
2. Классификация P0/P1; для P0 — предлагаемая задача (куда ставить).
3. Записать отчёт в `DS-agent-workspace/scout/results/YYYY/MM/DD/report.md` (+ `capture-candidates.md`, есть находки).
4. Находки отразить в DayPlan: секция «Наработки агентов → Ночные отчёты» читается как «Утренний отчёт (скаут, <время>)»; P0 — в «Требует внимания».
5. Недоступный источник — строка деградации в отчёт, коммит DayPlan не блокирует.

Запрещено: запускать субагента, ставить скаут в планировщик, гонять два прогона параллельно.
