# day-close.after.reflection — блок «Рефлексия вечера» перед финальным коммитом (WP-007 Ф1)

> **Hook:** `day-close` / `after` (шаг 10a — до финального коммита 10b, правки попадают в тот же коммит).
> **Смысл:** рефлексия из «вспоминает агент» становится обязательной точкой закрытия дня.
> **Граница (правило пилота, 11.11):** ритуал 2–3 минуты и не конкурирует с H-005 (отбой) —
> вечер без ресурса закрывается честной строкой, догон на Day Open легален.
> **Политика отказов:** bash-блок никогда не блокирует закрытие (exit 0).

```bash
if [ -f "/tmp/iwe-dry-run.flag" ]; then
    echo "[reflection] dry-run active, skipping"
    exit 0
fi
GOV="${IWE_GOVERNANCE_REPO:-DS-strategy}"
WS="${IWE_ROOT:-${IWE:-$HOME/IWE}}"
TODAY=$(date +%F)
PLAN="$WS/$GOV/current/DayPlan $TODAY.md"
[ -f "$PLAN" ] || PLAN="$WS/$GOV/archive/day-plans/DayPlan $TODAY.md"
if [ ! -f "$PLAN" ]; then
    echo "[reflection] DayPlan за $TODAY не найден (strategy_day?) — проверка неприменима"
    exit 0
fi
if grep -q "Рефлексия вечера" "$PLAN"; then
    echo "[reflection] 🟢 блок «Рефлексия вечера» в DayPlan $TODAY есть"
else
    echo "[reflection] 🟡 блока «Рефлексия вечера» нет — ДО финального коммита спроси пилота три вопроса («сработало / не сработало / главное на завтра») и впиши ответы в «Итоги дня» (шаблон: memory/templates-dayplan.md, Шаблон итогов дня); вечер без ресурса → строка «рефлексия не проведена (вечер без ресурса)»"
fi
exit 0
```

Порядок для агента: (1) если блок есть и заполнен — ничего; (2) блок есть, ответы «…» — спросить ответы в чате, вписать; (3) блока нет — вписать каркас из шаблона и задать три вопроса. Fallback: пилот ответил не в чате (бот/почта) — транскрибировать с пометкой «(через сообщение)». Тишина в блоке недопустима: либо ответы, либо строка «не проведена».
